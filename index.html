Tutorial de Uso

A continuación se presenta un breve tutorial sobre cómo usar la página:

  • Calendario: Aquí puedes ver las fechas importantes relacionadas con los animales.
  • Registros Activos: Muestra los registros de animales que están actualmente activos.
  • Registros Anteriores: Muestra los registros de animales cuyo parto ya ha pasado.
  • Agregar Nuevo: Permite añadir nuevos registros de animales a la base de datos.
  • Configuración: Puedes activar el modo oscuro desde aquí.
  • Notificaciones: Muestra las alertas sobre eventos importantes.
